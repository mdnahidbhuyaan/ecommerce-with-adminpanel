# MERN Stack E-commerce with Admin Panel

A full-stack e-commerce web application built using the MERN stack. The project includes a shopping interface for users and an admin panel for managing products.

## Technologies Used

### Frontend
- React.js
- Redux Toolkit
- React Router
- Tailwind CSS
- Shadcn UI
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

### Tools
- Git and GitHub
- VS Code
- Cloudinary for image uploads

## Features

- User registration and login
- Admin authentication
- Admin dashboard
- Product management (Add, Edit, Delete)
- Product image upload
- Product listing
- Product filtering and sorting
- Product details page
- Shopping cart functionality *(update to match your completed features)*

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/mdnahidbhuyaan/ecommerce-with-adminpanel.git
```

### 2. Install frontend dependencies

```bash
cd ecommerce-with-adminpanel/client
npm install
```

### 3. Install backend dependencies

Open another terminal:

```bash
cd ecommerce-with-adminpanel/server
npm install
```

### 4. Configure environment variables

Create the required `.env` file for the backend and configure your MongoDB connection, JWT secret, and Cloudinary credentials according to your project configuration.

Never commit passwords, API secrets, or private credentials to GitHub.

### 5. Run the application

Start the backend and frontend in separate terminals using the appropriate scripts defined in each `package.json`.
